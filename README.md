### 1. Project Overview & Business Proposal

### Organisation Name

GamerPlayground 

### History of the Organisation

GamerPlayground started in 2026 as a passionate community of gaming purists responding to the rapid digital shift in the interactive media landscape. Witnessing digital storefronts systematically delisting classic titles and revoking user purchase licenses, the founders started a localized physical game trading club. To scale this preservation movement, GamerPlayground is evolving into a dedicated online consumer marketplace to keep tangible hard discs accessible worldwide. 

### Mission Statement

To preserve gaming history and guarantee true media ownership by providing collectors and gamers with reliable access to physical game discs. 

### Vision Statement

To become the world's most trusted sanctuary for physical media, where games are collected, owned, and cherished forever. 

### Target Audience Breakdown

* **Physical Media Purists:** Collectors demanding physical game boxes, original insert booklets, and high-shelf display values.
* **Preservationists:** Players concerned with server closures, digital delisting trends, and long-term history archival.
* **Gift Buyers:** Consumers prioritizing tangible, physically wrapped boxes for holiday gifts over abstract digital voucher codes.
* **Budget-Conscious Players:** Gamers relying on buying, testing, selling, and trading down physical game collections to fund their hobby.

### 2. Platform Strategy & Performance Tracking

### Website Goals

* **Exclusive Marketplace:** Establish a reliable portal entirely clear of digital download keys or ongoing internet verification check-ins.
* **Grading Clarity:** Provide complete transparency over case conditions, surface scratches, and regional data (PAL/NTSC).
* **Community Integration:** Connect collectors securely through user-driven trade-in valuation streams.

### Key Performance Indicators (KPIs)

* **Sales Conversion Rate:** Tracking the percentage of buyers checking out actual physical games.
* **Bounce Rate:** Reviewing product data card clarity based on how long users spend viewing disc condition assessments.
* **Trade Submissions Volume:** Measuring the frequency of incoming trade-in appraisal forms submitted per week.

### 3. Technical Requirements & Design Execution

### Design Scope Expansion (HTML & CSS Integration)

Per the expanded assignment requirements, this system transitions from pure structural markup into a styled, responsive presentation using an external CSS stylesheet. 

* **HTML5 Structure:** Provides the semantic bedrock (<header>, <section>, <nav>, <form>, <footer>) ensuring accessible document structure across all sub-pages.
* **External CSS Custom Engine (style.css):** Decouples structural presentation from logic. Handles layouts globally using advanced **CSS Grid** and **Flexbox** engines.
* **Visual Theme & Micro-Interactions:** Utilizes a dark-mode gaming aesthetic featuring dynamic layout transitions (translateY), accent focal borders (#ff4757), and strict image rendering parameters (object-fit: cover) to avoid media stretching.
* **No JavaScript:** Relies entirely on native HTML form processing fields and semantic anchor routing paths (href).

### Sitemaps & Page Inventory

The platform structure consists of the following modular files, linked via the global layout <nav> panel: 

* index.html (Homepage) - Showcase hero welcome banner, value pillars, and trending grid overview.
* about.html (About Us) - Extensive organizational history and structural multi-column target audience segment profiles.
* products.html (Product Catalog) - Grid layout showcasing distinct physical titles categorized with standalone purchasing action hooks.
* contact.html (Contact Us) - Flex-based asymmetric wrapper cleanly rendering validation forms alongside physical hub distribution data.
* community.html (Community and Trade-ins) - Core user evaluation portal detailing condition grading metrics and transaction submission pathways.
